# Clipper

Десктопное приложение для Windows и Mac: режет стримы на клипы по 20, 30 или 60 секунд.

## Скачать

Свежая сборка из `main` (обновляется после каждого коммита, все файлы также на странице [Releases](../../releases/tag/latest)):

| Система | Файл |
| --- | --- |
| Windows, установщик | [Clipper-Setup.exe](../../releases/download/latest/Clipper-Setup.exe) |
| Windows, без установки | [Clipper-Portable.exe](../../releases/download/latest/Clipper-Portable.exe) |
| Mac с чипом Apple (M1 и новее) | [Clipper-arm64.dmg](../../releases/download/latest/Clipper-arm64.dmg) |
| Mac с процессором Intel | [Clipper-x64.dmg](../../releases/download/latest/Clipper-x64.dmg) |

Пока сборка идёт (около 5–10 минут после коммита), ссылки могут не открываться. Состояние смотри на вкладке Actions.

## Что умеет

- **По звуку**: ищет реакции стримера. Анализ смотрит только голосовой диапазон (200–3400 Гц), поэтому громкая музыка и взрывы в игре не считаются. Момент берётся, когда голос заметно громче обычного (крик, смех, эмоция), и только если вокруг есть речь. Тишина и заглушённые участки (в записях Twitch так закрывают музыку) отбрасываются. Клипы не пересекаются, заказать можно до 100.
- **Подряд**: режет всё видео на равные куски.
- **Импорт**: перетащи видео в окно или выбери файл. Можно вставить ссылку, тогда видео скачается через yt-dlp (до 1080p).
- **Анализ один раз**: звук анализируется сразу после загрузки или импорта видео, пока ты выбираешь параметры. Длину клипа и количество потом можно менять без повторного анализа.
- **Звук в клипах**: берутся все звуковые дорожки видео и сводятся в одну (у стримов голос и игра бывают на разных дорожках). Каждый готовый клип проверяется на тишину; если звук пропал, клип режется заново другим способом, а если и это не помогло, он отмечается в списке и в `timecodes.txt`.
- **Удаление видео**: кнопка «Убрать» снимает видео с экрана. Если видео скачало приложение, можно ещё отправить файл в корзину. Твои собственные файлы приложение не удаляет никогда.
- **Быстрая нарезка**: без перекодирования, почти мгновенно, но начало клипа может сдвинуться на пару секунд до ближайшего ключевого кадра. Без галочки клипы перекодируются и режутся точно.
- В папке с клипами лежит `timecodes.txt`, а в окне можно скопировать таймкоды и порезать самому.

Клипы сохраняются в `Видео/Clipper` (папку можно сменить).

## Запуск из исходников

```bash
npm install
npm start
```

Нужен Node.js 20 или новее. ffmpeg и ffprobe ставятся вместе с зависимостями, отдельно ставить не нужно.

## Сборка exe и dmg

Локально:

```bash
npm run dist:win   # на Windows
npm run dist:mac   # на Mac
```

Через GitHub Actions сборка запускается сама при каждом пуше в `main` (или вручную: **Actions → Build → Run workflow**). Готовые файлы публикуются в релиз `latest`. Если создать тег вида `v0.1.0`, появится отдельный релиз с этой версией.

## Проверка движка

```bash
npm test
```

Тест генерирует видео с тремя известными громкими моментами и проверяет поиск пиков, нарезку, длины клипов, отмену и входные данные.

## Заметки

- Mac-сборка не подписана: при первом запуске открывай через правый клик → «Открыть».
- Скачивать можно только то, что тебе разрешено скачивать. yt-dlp загружается при первом использовании ссылки и обновляется раз в неделю.
- Отбор идёт по голосу и громкости, а не по смыслу сказанного: он примерный, лучшие клипы стоит просмотреть. Если в записи Twitch звук заглушён из-за музыки, вернуть его нельзя: такие участки приложение пропускает.
